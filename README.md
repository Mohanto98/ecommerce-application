# ShopNest E-commerce Frontend Starter

Static multi-page starter built with HTML5, CSS3 and Bootstrap 5.3.

## Pages
- `login.html`
- `register.html`
- `forgot-password.html`
- `index.html`
- `products.html`
- `product-details.html`
- `cart.html`
- `order.html` (checkout)
- `order-confirmation.html`
- `my-orders.html`

## Run
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Notes
- This is a frontend-only demo. Forms, filters, cart quantities, payment, and order placement are not connected to a backend.
- Bootstrap is loaded from jsDelivr, so an internet connection is needed for Bootstrap styling and components.
- Shared styles are in `css/style.css`.
- Replace emoji product artwork and demo product details with real images and data later.

## Suggested next steps
1. Review each page and customize the brand, colors and product content.
2. Add JavaScript for form validation, cart updates and navigation state.
3. Connect forms and product/order actions to Spring Boot REST APIs.
4. Add authentication and authorization with Spring Security.
